# 🧠 Daily Neuron — Кибер-Редакционный Агрегатор ИИ-Новостей (Case 04)

Daily Neuron — медиа-платформа и агрегатор трендов искусственного интеллекта в стиле **швейцарской кибер-типографики**, оснащенный встроенным Hype-Meter, переключателем режимов чтения (10s TL;DR vs Deep Tech) и Telegram-ботом с подписками.

---

## ⚡️ Ключевые возможности

### 1. Веб-интерфейс (Swiss Cyber-Editorial)
- **Швейцарская модульная сетка:** Высококонтрастный монохром (`#0A0A0C` / `#F9F9FB`), моноширинные теги (JetBrains Mono), кислотные акценты (циан `#00F0FF`, лайм `#CCFF00`).
- **AI Hype-Meter (0–100%):** Динамическая шкала популярности, рассчитываемая по динамике звезд репозиториев на GitHub и загрузок весов на HuggingFace.
- **Двухрежимное чтение:**
  - *«Коротко за 10 секунд» (10s TL;DR):* 3 ключевых вывода без воды для занятых фаундеров и тимлидов.
  - *«Технический разбор» (Deep Dive):* Архитектура модели, квантование (FP8, AWQ), бенчмарки (MMLU, HumanEval) и требования к VRAM.
- **Фильтрация по категориям:** `LLM`, `Video Gen`, `Open Source`, `Agents`.

### 2. Telegram-бот (Aiogram 3.x)
- Утренний дайджест в 09:00 с топовыми трендами за сутки.
- Подписка на конкретные рубрики (`/subscribe llm`, `/subscribe agents`, `/subscribe video`, `/subscribe oss`).
- Команда мгновенного дайджеста `/digest`.

---

## 🚀 Запуск и тестирование

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-сервера
```bash
python web/app.py
# Интерфейс доступен: http://localhost:8004
```

### 3. Запуск Telegram-бота
```bash
python bot/bot.py
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
